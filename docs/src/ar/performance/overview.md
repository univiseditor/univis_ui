# الأداء والتشخيص

المشروع يحتوي أداتين أساسيتين للأداء:

1. `LayoutCache` لتقليل الحسابات.
2. `LayoutProfilingPlugin` لقياس الزمن وعرض طبقة المراقبة.

## أين تراقب الأداء؟

- نسبة الاتساخ وعدد العقد المعاد حسابها.
- زمن المرور الصاعد والهابط.
- زمن تحديث المواد.
- عدد المواد الجديدة مقابل المعاد استخدامها.
