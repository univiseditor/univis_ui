# الأمثلة

هذا هو الفهرس المرجعي الرسمي للأمثلة داخل مساحة العمل.

شغّل أي مثال بصيغة:

```bash
cargo run -p <package> --example <name>
```

## دلالة التصنيفات

- `تعليمي`: مثال تعليمي مركّز
- `استعراضي`: عرض أكبر أو أكثر صقلًا
- `تحقق-سريع`: مثال مناسب للتحقق الآلي أو اليدوي قبل الإصدار

## مسار التعلم المقترح

### `hello_world`

- الحزمة: `univis_ui`
- الغرض: أصغر نقطة دخول على مستوى الواجهة المجمعة مع `UnivisUiPlugin` وجذر وعقدة مرئية واحدة.
- الأنسب لـ: أول تشغيل وتأكد الاستيراد.
- النوع: `تعليمي`, `تحقق-سريع`

### `root_screen_hud`

- الحزمة: `univis_ui_engine`
- الغرض: يثبت أن `URootUi::screen()` يبقى ثابتًا على مساحة الرؤية بينما يتحرك الجذر العالمي مع الكاميرا.
- الأنسب لـ: فهم الواجهة الثابتة على الشاشة ومساحات الجذور.
- النوع: `تعليمي`, `تحقق-سريع`

### `root_world_scale`

- الحزمة: `univis_ui_engine`
- الغرض: يبين كيف يمكن لنفس مساحة الرسم المنطقية أن تنتج أحجامًا فيزيائية مختلفة عبر `meters_per_unit`.
- الأنسب لـ: معايرة الحجم في جذور العالم.
- النوع: `تعليمي`, `تحقق-سريع`

### `root_fit_content`

- الحزمة: `univis_ui_engine`
- الغرض: يشرح جذور العالم التي تقيس نفسها من المحتوى عبر `UiCanvasSize::FitContent`.
- الأنسب لـ: البطاقات العائمة، والمفتشات، ولوحات العقد.
- النوع: `تعليمي`, `تحقق-سريع`

### `root_capsule_overlap`

- الحزمة: `univis_ui_engine`
- الغرض: يوضح كبسولات الجذور المغلقة بحيث لا يتجاوز ابن بارز جذرًا أخرى أعلى منه.
- الأنسب لـ: node graph وقواعد التراكب بين الجذور.
- النوع: `تعليمي`, `تحقق-سريع`

### `border_light_3d`

- الحزمة: `univis_ui_engine`
- الغرض: يفحص مسار `World3d` المضيء مع نمط مناسب لتأثيرات bloom.
- الأنسب لـ: التحقق البصري من الرندر ثلاثي الأبعاد و`UPbr`.
- النوع: `تعليمي`, `تحقق-سريع`

### `interaction`

- الحزمة: `univis_ui_interaction`
- الغرض: يشرح كيف تحجب العناصر المتداخلة الضربات أو تتجاهلها أو تمررها.
- الأنسب لـ: دلالات الالتقاط وسلوك المراقبين.
- النوع: `تعليمي`, `تحقق-سريع`

### `widgets`

- الحزمة: `univis_ui_widgets`
- الغرض: مشهد يستعرض شريحة واسعة من الوحدات الجاهزة.
- الأنسب لـ: أخذ نظرة سريعة على السطح العام للوحدات.
- النوع: `تعليمي`

### `text_label`

- الحزمة: `univis_ui_widgets`
- الغرض: يستعرض قياس النص، والقص، والفيض، و`autosize` في `UTextLabel`.
- الأنسب لـ: فهم رندر النصوص.
- النوع: `تعليمي`

### `text_field`

- الحزمة: `univis_ui_widgets`
- الغرض: يشرح الإدخال النصي، وأنماط التصفية، ورسائل التغيير والإرسال.
- الأنسب لـ: نماذج الإدخال و`UnivisTextFieldPlugin`.
- النوع: `تعليمي`

### `panel_window`

- الحزمة: `univis_ui_widgets`
- الغرض: يوضح سلوك اللوحات العائمة القابلة لتغيير الحجم.
- الأنسب لـ: نوافذ الأدوات والتخطيطات الشبيهة بالمحررات.
- النوع: `تعليمي`

### `scroll_view`

- الحزمة: `univis_ui_widgets`
- الغرض: يشرح التمرير داخل المساحات ذات الفيض.
- الأنسب لـ: القوائم الطويلة والمحتوى المقيد.
- النوع: `تعليمي`

## الفهرس الكامل

### `univis_ui`

| المثال | الغرض | الأنسب لـ | النوع |
| --- | --- | --- | --- |
| `hello_world` | تطبيق واجهة مجمعة بسيط مع جذر واحدة ونص واحد. | أول تشغيل | `تعليمي`, `تحقق-سريع` |
| `complex_dashboard` | لوحة متكاملة تعتمد على عدة وحدات جاهزة معًا. | تركيب واجهة أعلى مستوى | `استعراضي` |
| `card_profile` | بطاقة تعريف مصقولة مع مظهر أعلى جودة وbloom اختياري. | بطاقة واجهة مجمعة متقنة | `استعراضي`, `تحقق-سريع` |
| `sci_fi` | مشهد واجهة أكبر يستعرض كامل السطح العام. | عرض بصري نهائي | `استعراضي`, `تحقق-سريع` |

### `univis_ui_engine`

| المثال | الغرض | الأنسب لـ | النوع |
| --- | --- | --- | --- |
| `alignment` | مرجع صغير لقواعد المحاذاة. | المحاذاة | `تعليمي` |
| `border_light_3d` | لوحة `World3d` مضيئة مناسبة للتحقق البصري. | مسار الرندر ثلاثي الأبعاد | `تعليمي`, `تحقق-سريع` |
| `ex_node` | مثال منخفض المستوى لكتابة العقد يدويًا. | بدائيات المحرك | `تعليمي` |
| `layout_cache` | يستعرض أو يضغط سلوك الذاكرة المؤقتة للتخطيط. | تشخيص الذاكرة المؤقتة | `تعليمي` |
| `layout_case_alignment_overflow` | حالة مركزة للمحاذاة والفيض. | حالات المحلل الطرفية | `تعليمي` |
| `layout_case_flex_wrap` | يوضح سلوك الالتفاف في flex. | التفاف `flex` | `تعليمي` |
| `layout_case_grid_auto_flow` | يوضح التدفق التلقائي في `grid`. | التموضع التلقائي في `grid` | `تعليمي` |
| `layout_case_grid_tracks` | يوضح أحجام مسارات `grid` والتموضع. | مسارات `grid` | `تعليمي` |
| `layout_case_masonry_ext` | يفحص امتدادات حاويات `masonry`. | ضبط `masonry` | `تعليمي` |
| `layout_case_radial` | يوضح التوزيع الشعاعي. | التخطيط الشعاعي | `تعليمي` |
| `layout_case_stack` | يوضح دلالات التخطيط المتراكم. | التخطيط المتراكم | `تعليمي` |
| `layout_solver_no_widgets` | مشهد يركز على المحلل من دون الاعتماد على الوحدات الجاهزة. | تشخيص التخطيط الصرف | `تعليمي` |
| `layout_solver_ultra_complex` | مشهد أكبر للضغط على المحلل. | ضغط المحلل | `تعليمي`, `تحقق-سريع` |
| `masonry` | عرض أعلى مستوى لتخطيط `masonry`. | مرجع `masonry` | `تعليمي` |
| `root_screen_hud` | يؤكد سلوك الواجهة الثابتة على الشاشة لـ `URootUi::screen()`. | جذور الشاشة | `تعليمي`, `تحقق-سريع` |
| `root_world_scale` | يقارن بين حجم مساحة الرسم المنطقية والحجم الفيزيائي في العالم. | `meters_per_unit` | `تعليمي`, `تحقق-سريع` |
| `root_capsule_overlap` | يوضح كبسولات الجذور المغلقة عند التداخل. | التراكب بين الجذور | `تعليمي`, `تحقق-سريع` |
| `root_fit_content` | يوضح جذور `World2d` و`World3d` المعتمدة على المحتوى. | الجذور المقاسة من المحتوى | `تعليمي`, `تحقق-سريع` |
| `texture` | مرجع لمسار الصور والخامات. | هندسة الصور | `تعليمي` |

### `univis_ui_widgets`

| المثال | الغرض | الأنسب لـ | النوع |
| --- | --- | --- | --- |
| `drag_value` | يوضح تغيير القيم بالسحب. | المدخلات الرقمية | `تعليمي` |
| `panel_divider` | يوضح استخدام `divider` داخل اللوحات. | تخطيط اللوحات | `تعليمي` |
| `panel_window` | لوحات عائمة قابلة لتغيير الحجم. | نوافذ الأدوات | `تعليمي` |
| `radio` | أزرار `radio` والمجموعات التابعة لها. | الخيارات المتبادلة | `تعليمي` |
| `scroll_view` | سلوك التمرير داخل الحاوية. | التمرير | `تعليمي` |
| `seekbar` | اختيار قيمة عبر شريط منزلق. | القيم المستمرة | `تعليمي` |
| `select` | قائمة اختيار منسدلة مع خيارات. | إدخال الاختيار الأحادي | `تعليمي` |
| `text_field` | حقول نصية قابلة للتحرير مع فلاتر ورسائل. | إدخال النص | `تعليمي` |
| `text_label` | قياس النص والفيض والقص و`autosize`. | رندر النص | `تعليمي` |
| `text_label_zoom` | وضوح النص عند تغيّر مستوى التكبير. | جودة النص تحت التكبير | `تعليمي` |
| `toggle` | سلوك المفتاح الثنائي. | حالات التشغيل/الإيقاف | `تعليمي` |
| `widgets` | مشهد عينات لعدة وحدات جاهزة. | أخذ نظرة سريعة | `تعليمي` |

### `univis_ui_interaction`

| المثال | الغرض | الأنسب لـ | النوع |
| --- | --- | --- | --- |
| `interaction` | يوضح الحجب والتجاهل والتمرير في الضربات. | دلالات الالتقاط | `تعليمي`, `تحقق-سريع` |

## أوامر مقترحة

```bash
cargo run -p univis_ui --example hello_world
cargo run -p univis_ui_engine --example root_fit_content
cargo run -p univis_ui_widgets --example text_field
cargo run -p univis_ui_interaction --example interaction
```
