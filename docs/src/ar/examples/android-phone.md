# شاشة تطبيق Android

توثق هذه الصفحة العرض الحي الحالي `android_phone`.

شغّله بالأمر:

```bash
cargo run --manifest-path android/android_phone_app/Cargo.toml
```

وتحتفظ الحزمة أيضًا بهدف مثال محلي باسم `android_phone` لاستخدامات Android الخاصة، لكن نقطة
الدخول أعلاه هي أسرع طريقة لمعاينة المشهد على سطح المكتب داخل هذا الفرع.

## ماذا يوضح؟

- سطح تطبيق متمركز بطابع Android من دون إطار هاتف مصطنع
- `UTextField` لحقل البحث العلوي
- `UToggle` و`USeekBar` داخل تخطيط إعدادات بسيط
- أزرار `UButton` صغيرة داخل صف تنقل سفلي
- تركيبًا ضيق العرض مبنيًا حول `URootUi::screen()`

## متى تشغله؟

- عندما تريد العرض الحي الحالي الذي ما يزال يشحن مع المستودع
- عندما تريد معايرة كثافة العناصر في مشاهد الإعدادات أو launcher أو companion app
- عندما تريد مشهدًا واحدًا يخلط التخطيط والوحدات الجاهزة والتفاعل داخل عرض ضيق

## ملاحظات عملية

- يستخدم المشهد `URootUi::screen()`، لذلك يبقى سطح التطبيق ثابتًا على مساحة الرؤية مثل HUD
- التخطيط ثابت عمدًا حتى تبقى عناصر التحكم الأساسية قابلة للوصول على أجهزة اللمس
- لمعرفة الملكية التاريخية للأمثلة، راجع [فهرس الأمثلة](index.md)
- وللتركيز على سلوك وحدات بعينها، قارنه مع [`text_field`](index.md#text_field) و[`scroll_view`](index.md#scroll_view) و[`widgets`](index.md#widgets)
