# التحقق البصري

تحدد هذه الصفحة الفحوص البصرية اليدوية الخفيفة التي ما تزال مهمة حتى بعد نجاح فحوص الوثائق والوثائق البرمجية المولدة وبناء الأمثلة.

## الهدف

- التقاط الكسور التي تمر بنجاح في البناء لكن تظهر بشكل خاطئ بصريًا
- الحفاظ على موثوقية الأمثلة الأكثر تمثيلًا
- تجنب تحويل لقطات الشاشة إلى شرط تحقق آلي صارم قبل أن يصبح ذلك مناسبًا للمشروع

## السياسة الحالية

- تبقى لقطات الشاشة مواد يدوية مرتبطة بتجهيز الإصدار، وليست ناتجًا إلزاميًا داخل التحقق الآلي
- يمكن أن يربط معرض الأمثلة بمراجع ثابتة عندما يكون ذلك مفيدًا
- ما يزال التحقق البصري مهمًا لسلوك الواجهة الثابتة على الشاشة، والقياس داخل العالم، ومظهر النصوص، وقواعد تراكب الجذور

## الأمثلة الأكثر تمثيلًا

شغّل هذه الأمثلة عندما يكون التعديل بصريًا أو غنيًا بالتفاعل:

```bash
cargo run -p univis_ui_engine --example root_screen_hud
cargo run -p univis_ui_engine --example root_world_scale
cargo run -p univis_ui_engine --example root_fit_content
cargo run -p univis_ui_engine --example root_capsule_overlap
cargo run -p univis_ui_widgets --example text_label
cargo run -p univis_ui_widgets --example panel_window
cargo run -p univis_ui_interaction --example interaction
```

## ما الذي يجب ملاحظته

### الواجهة الثابتة والجذور

- `root_screen_hud`: تبقى الواجهة الثابتة على الشاشة في مكانها بينما يتحرك الجذر العالمي مع الكاميرا
- `root_world_scale`: يبقى عنصر الشاشة ثابتًا بينما تختلف أحجام اللوحات العالمية فيزيائيًا
- `root_fit_content`: تلتف جذور العالم حول المحتوى المقاس من دون قص واضح أو نمو منفلت
- `root_capsule_overlap`: لا تخرج الأبناء البارزة بصريًا أو تفاعليًا فوق جذر آخر أعلى منها

### الوحدات الجاهزة والتفاعل

- `text_label`: يبقى القص والفيض و`autosize` مقروءًا ومقصودًا
- `panel_window`: تبقى مقابض تغيير الحجم وحركة اللوحة مفهومة
- `interaction`: يبقى الحجب والتجاهل والتمرير مطابقًا لنموذج الالتقاط الموثق

## ما المتوقع قبل الإصدار

- نفّذ جولة تحقق بصري واحدة على الأقل عندما يؤثر التعديل في الرندر أو دلالات التخطيط أو الالتقاط أو الأمثلة الرئيسية
- التقط صورًا فقط عندما تضيف قيمة حقيقية للتواصل مع الإصدار أو لجودة معرض الأمثلة
- لا تجعل توليد الصور شرطًا يعطل مساهمة يومية عادية
